# Security policy

Do **not** include sensitive logs, API tokens, passwords, private traces or identifiable customer data in public issues or pull requests.

If you identify a security problem in this project, use the **Report a vulnerability** / private security-advisory feature on the GitHub repository if available, rather than a public issue. Maintainer: [sarahsalary](https://github.com/sarahsalary).

No audit, external-service integration test, or production security guarantee is claimed. When using webhooks, OTLP receivers or remote Loki endpoints, secure endpoints and credentials yourself.
