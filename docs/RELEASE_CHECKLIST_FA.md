# چک‌لیست پیش از انتشار عمومی

این پروژه به‌صورت آزمایشی (Beta) منتشر می‌شود؛ این فهرست به معنای تأیید امنیت یا حقوق تمام اجزای کد نیست.

- [ ] تمام کدها و اسناد را بازبینی و منابع و مجوزهای ثالث را بررسی کرده‌ام؛ اطلاعات واقعی کاربران، رمزها یا توکن‌ها را حذف کرده‌ام.
- [ ] نام و نسبت حق نشر `sarahsalary` و نمایش عمومی ایمیل `saraasaalari@yahoo.com` در `pyproject.toml` مورد تأیید من است.
- [ ] نام PyPI یعنی `rootrewind` هنگام ثبت واقعاً قابل‌استفاده است.
- [ ] `git status --short` و `git diff --cached --stat` را قبل از Push کنترل کرده‌ام؛ `.venv`، `.env`، logهای خصوصی و فایل‌های ذخیره‌شدهٔ واقعی نباید عمومی شوند.
- [ ] نصب پکیج، `pytest` و `rootrewind --help` در ویندوز من موفق بوده است.
- [ ] مخزن عمومی `sarahsalary/time-travel-debugger` وجود دارد و GitHub Actions CI سبز است.
- [ ] مالکیت و سیاست دسترسی حساب PyPI / TestPyPI، و Trusted Publisher مربوط به workflow دقیقاً تأیید شده است.
- [ ] در اولین انتشار، ابتدا در TestPyPI آزمایش شده و Wheel/SDist مطابق انتظار هستند.
- [ ] توضیحات منتشرشده ادعای اجرای معکوس در سطح متغیر و CPU یا اثبات قطعی علت رخداد ندارند.
- [ ] در صورت انتشار عمومی، اطلاع دارم که مجوز MIT اجازه استفاده و بازنشر تجاری را به دیگران می‌دهد.

**هیچ دستور این پکیج به‌صورت خودکار پروژهٔ PyPI یا مخزن GitHub را ایجاد نمی‌کند.** انتشار نیازمند ورود و تأیید حساب کاربری مربوطه است.
